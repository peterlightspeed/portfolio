# Portfolio

Personal portfolio showcasing my AI, backend, Python, Go, and SaaS projects.

## Overview

A central hub for my work as a developer, highlighting projects across artificial intelligence, backend engineering, and full-stack SaaS builds. Hosted via GitHub Pages.

## Features

- Curated showcase of AI, Python, and Go projects
- SaaS project highlights
- Responsive design built with Bootstrap
- Deployed directly through GitHub Pages

## Tech Stack

- HTML
- Bootstrap
- Python
- Go

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/peterlightspeed/portfolio.git
   cd portfolio
   ```
2. Open `index.html` in your browser, or serve locally:
   ```bash
   npx serve .
   ```
3. Live version available via GitHub Pages.
